# Лабораторна робота №2
## Встановлення Docker та запуск першого контейнера

### Мета роботи
Ознайомитися з технологією контейнеризації, навчитися встановлювати Docker та отримати практичний досвід запуску і керування контейнерами.

### Теоретичні відомості

**Docker** — це платформа для запуску програм в окремих контейнерах.

Основні поняття:
- **Контейнер** — середовище, у якому працює програма та необхідні для неї компоненти.
- **Образ (Image)** — шаблон для створення контейнера.
- **Docker Hub** — сховище для зберігання та поширення образів.
- **Docker Engine** — інструмент для створення та керування контейнерами.

### Хід роботи

1. Перевірено системні вимоги для встановлення Docker.
2. Виконано встановлення Docker згідно з офіційною інструкцією: https://docs.docker.com/engine/install/
3. Перевірено встановлення командою:

```bash
docker --version
```

4. Запущено тестовий контейнер:

```bash
docker run hello-world
```

5. Переглянуто список усіх контейнерів:

```bash
docker ps -a
```

6. За потреби видалено контейнер:

```bash
docker rm <container_id>
```

7. Запущено вебсервер NGINX:

```bash
docker run -d -p 8080:80 nginx
```

8. Перевірено роботу вебсервера у браузері за адресою:

```text
http://localhost:8080
```

### Основні команди Docker

| Команда | Призначення |
|---|---|
| `docker --version` | Перевірка версії Docker |
| `docker pull <image>` | Завантаження образу |
| `docker images` | Перегляд образів |
| `docker run <image>` | Запуск контейнера |
| `docker ps` | Перегляд активних контейнерів |
| `docker ps -a` | Перегляд усіх контейнерів |
| `docker stop <container_id>` | Зупинка контейнера |
| `docker start <container_id>` | Запуск контейнера |
| `docker restart <container_id>` | Перезапуск контейнера |
| `docker rm <container_id>` | Видалення контейнера |
| `docker rmi <image_id>` | Видалення образу |
| `docker logs <container_id>` | Перегляд логів |
| `docker network ls` | Перегляд мереж |
| `docker volume ls` | Перегляд томів |

### Результат роботи

Під час лабораторної роботи встановлено Docker, запущено тестовий контейнер `hello-world` та вебсервер NGINX. Роботу вебсервера перевірено через браузер.
